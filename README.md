# Studio Kuo — Photography Portfolio

Personal photography portfolio for a Bay Area portrait, family, maternity, and event photographer.

Single-file static site: open `index.html` in a browser, or deploy to GitHub Pages.

## Deploying to GitHub Pages
1. Push this folder to a repo named `<username>.github.io`
2. In repo Settings → Pages, source = `main` branch / root
3. Visit `https://<username>.github.io`

## Updating
- Edit text and prices in `index.html`
- Add or replace photos in `photos/` (keep filenames the same to swap without code changes)
